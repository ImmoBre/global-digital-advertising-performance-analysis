# Global Digital Advertising Performance Analysis

## Overview

An end-to-end Data Analytics project analyzing digital advertising
performance across Google Ads, Meta Ads, and TikTok Ads using **Python,
SQL, and Power BI**.

## Objectives

-   Understand campaign performance
-   Assess data quality
-   Perform exploratory data analysis
-   Engineer business metrics
-   Generate executive insights
-   Build an interactive Power BI dashboard
